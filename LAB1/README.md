# LAB 1 - Embedded Linux

## Overview
Build and boot an Embedded Linux system using QEMU
with the ARM VExpress platform.

## Deliverables
- Linux kernel image (zImage)
- Device Tree Blob (vexpress-v2p-ca9.dtb)
- Initial RAM filesystem (initramfs.cpio.gz)
- U-Boot binary
- Linux kernel configuration
- Root filesystem init script
- Original LAB1 submission archive

## Platform
- Architecture: ARM
- Board: VExpress
- Kernel: Linux 5.15
- Emulator: QEMU
